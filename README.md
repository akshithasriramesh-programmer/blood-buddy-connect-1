Blood Buddy Connect

Blood Buddy Connect – Urgent Blood Donor and Patient Network

About the Project

Blood Buddy Connect is a web-based platform designed to connect blood donors with patients who urgently need blood. It helps users find suitable donors and simplifies communication during emergency situations.

Key Features

- Donor Registration
- Patient Registration
- Blood Group Selection
- Donor Search
- Emergency Blood Requests
- Donor and Patient Connection

Technologies Used

- HTML
- CSS
- JavaScript
- React
- TypeScript
- Vite

Project Purpose

To make finding blood donors easier, faster, and more accessible during medical emergencies.
